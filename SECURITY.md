# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest desktop release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory for this repository, include reproduction steps and affected versions, and allow a reasonable period for a fix before disclosure.

## Security controls

Pull requests run unit tests, core and full static checks, and dependency review. CodeQL scanning and Dependabot monitor the current default branch for code and dependency alerts across Python, the web application, and GitHub Actions.
