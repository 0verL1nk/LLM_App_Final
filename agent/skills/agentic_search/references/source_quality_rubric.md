# Source Quality Rubric

Assess each source in the context of the current claim:

- credibility: authority and publication trust
- relevance: alignment with current sub-query
- recency: freshness for time-sensitive claims
- consistency: agreement with independent sources

Do not use a fixed formula. A highly credible source can still be irrelevant, an old source can be correct
for a historical claim, and agreement between dependent sources is not independent corroboration. Record a
short justification and the unresolved limitations for every source used in a key conclusion.

## Conflict Handling

- If credible, directly relevant sources conflict, keep both claims and mark "conflict".
- If only a weakly justified source supports a claim, mark "weak evidence".
- Never convert weak/conflicting evidence into definitive conclusions.
