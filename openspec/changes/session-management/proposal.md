# Session Management(会话重命名与分支删除)

## Why

研究脉络是"主会话 + 探索分支"两级结构,但会话一旦创建就不可改名、不可
删除:探索分支试错多了会无限堆积,列表里只剩 "探索分支 1/2/3…" 这类
无信息量的默认名,用户无法整理自己的研究脉络。"研究可以延续"的产品
叙事缺少最基本的资料整理能力。

## What Changes

1. **重命名**:主会话与探索分支均可改名(行内编辑或对话框);列表、
   浏览器标签标题联动更新;不生成新的会话记录。
2. **删除分支**:仅探索分支可删除(主会话受保护);确认对话框显示
   消息数;删除后从脉络列表消失,其消息/运行记录不再出现在任何列表,
   存储行按软删除标记保留以维持 run 事件外键完整性。
3. **归属与安全**:路由校验项目/用户归属;删除幂等;不可删除主会话
   (返回明确错误,前端不提供入口)。

## Non-goals

- 不做会话移动/合并/归档、分支再嵌套(结构仍为两级)。
- 不做消息级删除或编辑。
- 不做导出。
- 不删除运行事件日志的物理行(run 事件是审计事实,仅从会话视图隐藏)。

## Impact

- Backend:`agent/adapters/sqlite/project_repository` 会话标题更新与
  软删除(级联隐藏消息列表)、FastAPI 会话路由(PATCH/DELETE,归属与
   主会话保护)。
- Web:research-session-list 行内操作(重命名/删除)、确认对话框、
   路由守卫(删除后跳回主脉络)。
- Tests:重命名传播、删除级联视图、主会话保护、幂等、归属校验。
- Docs:README 研究脉络描述更新。
